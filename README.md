# Generador de Memorias de Cálculo — P. Electric S.A.S.

Aplicación del Departamento Civil para armar las memorias de cálculo de estructuras metálicas (NSR-10).

**Abrir:** https://solarsolutions2026.github.io/generador-memorias-civil/

## Instalar en el celular
1. Abre el enlace en Chrome.
2. Menú ⋮ → **Agregar a la pantalla principal**.

## Quién puede hacer qué
- **Ingeniero:** crea y edita memorias, configura los pies de página y la firma.
- **Consulta:** ve y descarga las memorias aprobadas.

Las cuentas se crean en Supabase → Authentication → Add user.
